ASSESSMENT 3.2 - LINEAR DATA STRUCTURES

This folder contains four separate Python programs based on Assessment 3.1.
The letters used are ENONSAON.

FILES
1. array_program.py
   Adds letters to a Python list and removes them from the beginning.

2. singly_linked_list_program.py
   Creates linked-list nodes, adds each letter at the end, and removes from the head.

3. stack_program.py
   Pushes letters onto a stack and pops them using LIFO.

4. queue_program.py
   Enqueues letters and dequeues them using FIFO.

HOW TO RUN IN PYCHARM
1. Extract the ZIP file.
2. Open the extracted folder in PyCharm.
3. Open one of the .py files.
4. Right-click inside the file and select Run.
5. Run each of the four files separately.

EXPECTED REMOVAL ORDERS
Array: E, N, O, N, S, A, O, N
Singly Linked List: E, N, O, N, S, A, O, N
Stack: N, O, A, S, N, O, N, E
Queue: E, N, O, N, S, A, O, N

Each program adds all letters first, then removes them one at a time until empty.
